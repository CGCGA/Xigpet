# Reference implementations

The memory system was informed by the hybrid lexical search, source references,
and reversible context-folding design of **billion-context / acp-kernel**:
https://github.com/ranxianglei/billion-context

The mood system was informed by the gradual changes, decay, and one-use context
design of **dsh-feiyu-mood**:
https://github.com/Yuuyuko-uu/dsh-feiyu-mood
